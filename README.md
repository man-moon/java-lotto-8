# java-lotto-precourse

## 기능 요구 사항
### 입력
1. 로또 구입 금액을 입력받는다.  
   [예외 상황]
   - 숫자로만 이루어진 입력이 아닌 경우
   - 0원 미만, 1000억 초과의 입력인 경우
   - 구입 금액이 1000원으로 나누어 떨어지지 않는 경우

2. 당첨 번호와 보너스 번호를 입력받는다.  
   [예외 상황]
   - 당첨 번호가 `숫자,숫자,숫자,숫자,숫자,숫자` 형식 이외의 입력인 경우
   - 각각의 번호가 1이상 45이하의 값이 아닌 경우
   - 당첨 번호와 보너스 번호에 중복된 값이 있는 경우
   - 당첨 번호가 6개, 보너스 번호가 1개가 아닌 경우
   - 보너스 번호가 숫자로만 이루어진 입력이 아닌 경우

3. 올바른 입력이 들어오지 않는다면, 에러 메시지를 출력하고 그 부분부터
   입력을 다시 받는다.

### 핵심 로직
1. 로또 발행
   - 1000원으로 1개의 로또를 발행할 수 있다.
   - 로또는 1~45 사이의 무작위 번호 6개로 이루어진다.  
   [예외 상황]
     - 발행된 1개의 로또에서 중복된 번호가 있는 경우

2. 당첨 확인
   - 발행된 로또의 번호와 당첨 및 보너스 번호의 일치 여부를 판단하여
     당첨 순위와 금액을 확정한다.
     - 3개 일치: 5등 5,000원
     - 4개 일치: 4등 50,000원
     - 5개 일치: 3등 1,500,000원
     - 5개 일치 + 보너스 번호 일치: 2등 30,000,000원
     - 6개 일치: 1등 2,000,000,000원

### 출력
1. 발행한 로또 수량 및 번호를 오름차순으로 출력한다.
2. 당첨 내역을 출력한다.
3. 수익률을 소수점 둘째 자리에서 반올림하여 출력한다.
